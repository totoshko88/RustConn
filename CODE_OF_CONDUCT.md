# Code of Conduct

RustConn follows the [GNOME Code of Conduct](https://conduct.gnome.org/).

It applies to everyone taking part in the project: in the GitHub repository's
issues, pull requests, discussions and code review comments, and in any other
channel that presents itself as an official RustConn venue.

## Reporting

If you see or experience behaviour that breaks the Code of Conduct, write to the
maintainer at **totoshko88@gmail.com**. Reports are kept confidential.

You can also report to the GNOME Code of Conduct Committee, for example when the
report concerns the maintainer. The
[reporter guide](https://conduct.gnome.org/reporter-guide/) explains how, and
what to include.

Please do not use these addresses for security vulnerabilities. Report those
through
[GitHub Security Advisories](https://github.com/totoshko88/RustConn/security/advisories/new),
as described in [SECURITY.md](SECURITY.md).
