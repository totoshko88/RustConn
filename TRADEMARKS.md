# RustConn name, icon and application ID

The code of RustConn is free software under GPL-3.0-or-later, with the
additional terms in [NOTICE](NOTICE). This file is about the project's identity,
not the code. It covers three things, none of them registered:

- the name "RustConn";
- the application icon (`rustconn/assets/icons/`);
- the application ID prefix `io.github.totoshko88`, as in
  `io.github.totoshko88.RustConn`.

They tell a user that a build comes from this project. Nothing here limits what
the GPL lets you do with the code.

## What you may do without asking

- Distribute the official builds unmodified, and redistribute unmodified
  copies of RustConn under its name.
- Package RustConn for an operating-system distribution under its name, icon
  and application ID. The patches a distribution applies to build, integrate or
  fix the program are fine, as long as they do not change its features.
- Refer to the project by name: in articles, reviews, tutorials, package lists
  and comparisons.
- Say that your project is "based on RustConn" or "a fork of RustConn".

## Forks distributed as separate projects

A modified version distributed as a separate project uses its own:

- name: "RustConn" alone is not allowed, "Foo, based on RustConn" is;
- application ID, one that does not begin with `io.github.totoshko88`;
- icon.

It also says that it is modified and by whom. It should take bug reports in
its own tracker.
